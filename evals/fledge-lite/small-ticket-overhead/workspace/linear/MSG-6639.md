## Description
On the Conversations list, the channel filter is a row of chips (Email / SMS / WhatsApp).
When a hotel disables a channel, the chip disappears from the row but the channel stays in
the applied filter set, so the list keeps filtering on a channel the user can no longer see
or clear. The only way out is a page reload.

Expected: when the available channel list changes, drop any selected channel that is no
longer available, and refetch the list.

Affects `frontend/` only. No API change.
