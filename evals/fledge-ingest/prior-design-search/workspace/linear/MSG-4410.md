# MSG-4410 — Dedupe guest journey messages for consecutive stays
Status: Canceled · Created 2026-03-02 · Canceled 2026-03-19 · Assignee: Priya Nair

## Description
Guests with consecutive reservations receive duplicate pre-arrival messages. Skip
scheduling for the later reservation when an earlier consecutive one exists.

## Comments
**Priya Nair** 2026-03-16: Implemented the pre-scheduling skip behind a flag. Broke in
the pilot: when a guest extended (a third reservation added after messages were already
scheduled), the new leg got everything and the existing legs couldn't be re-evaluated.
Also no handling for a leg being cancelled after its partner's messages were skipped —
the guest got nothing.
**Priya Nair** 2026-03-19: Canceling. Needs a send-time design, not a schedule-time one.
